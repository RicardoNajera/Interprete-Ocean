# Intérprete — Ocean Allure Costa Mujeres

Aplicación de traducción en vivo para el staff de hotel. Interfaz con la identidad
visual de **Ocean Signature Resorts**.

## Vistas

- **Inicio de turno** — selección de área y departamento.
- **Menú de oficio** — consola del copiloto IA y herramientas por oficio.
- **Traductor** — conversación bilingüe en vivo con micrófonos para equipo y huésped.

## Estructura

```
index.html          Documento raíz y carga de la aplicación
manifest.json       Manifiesto PWA
estilos.css         Sistema de diseño (paleta, tipografía, paneles cristal)
assets/             Logos, favicon e íconos de aplicación
src/
  app.js            Arranque y enrutado de vistas
  servicios/        Sesión de trabajador y UI dinámica
  vistas/           InicioTurnoView, MenuOficioView, TraductorView
```
